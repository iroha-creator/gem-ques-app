🛠️ アプリを安全に終了する3ステップ
プログラミングの世界では、ブラウザのバツボタンを閉じるだけでは、パソコンの裏側でアプリのプログラム（サーバー）が動き続けたままになってしまいます。

以下の手順で、裏側のプログラムも一緒に「完全にストップ」させましょう。

【ステップ1】 VS Code の画面に戻る
まずは、プログラムを動かしている大元のソフトである VS Code の画面をマウスでクリックして、一番手前に表示させます。

【ステップ2】 「魔法のキー」でプログラムを止める
画面の下側にある、文字がたくさん動いていた「黒い画面（ターミナル）」のどこでもいいので一度クリックします。

次に、キーボードを使って以下の操作をします。

キーボードの左下にある Ctrl（コントロール）キー を指で押しっぱなしにします。

Ctrl キーを押したままで、アルファベットの C（シー）キー をポンと1回だけ押します。

両方の指をキーボードから離します。

💡 何が起きる？
プログラミングの世界では、Ctrl + C は「今動いているプログラムを強制的にストップせよ！」という世界共通の命令（ショートカットキー）です。
成功すると、黒い画面の文字の動きがピタッと止まり、一番下の行に PS C:\Users\...> のように、新しく文字が入力できる状態のマークが表示されます。

【ステップ3】 ブラウザを閉じる
裏側のプログラムが完全に止まったのを確認したら、最後に ブラウザ の画面の右上にある「❌（バツ）ボタン」を押して画面を閉じて大丈夫です。

これで、アプリの終了作業はすべて完了です！パソコンにも余計な負荷はかかりません。
